1. Define the prediction target and horizon

Prediction target. At the end of calendar month t, using only dengue records, weather observations, and other information
available by the forecast issue cutoff, DengueWatch estimates the number of recorded dengue cases in calendar month t+1 for
each of Iligan City’s 44 barangays. The primary model target is this next-month barangay case count. A barangay is flagged
as a potential planning hotspot when its estimated count is at least 6. This is an internal planning threshold, not an official
outbreak declaration or a prediction of an individual resident’s health status.

date; the issue date and data cutoff must be shown. Actual weather or case information that became available after the issue
cutoff must not be used as a predictor. The target is the following month’s observed count, not a risk label derived from the
same month’s input count.

4. Chronological validation and leakage controls
Replace the random train-test split and repeated tuning against the test set with the following protocol. All barangays from the
same calendar month remain together in one temporal partition.
  Training period: February 2020-November 2023. Fit learned preprocessing and the Random Forest pipeline using training
data only.
  Validation period: December 2023-February 2025. Select features and tune parameters using this period and training data
only.
  Final test: forecast inputs from March 2025-June 2026, evaluated against target months April 2025-July 2026. Lock this
period before model tuning and score it once after all decisions are frozen.
  At each forecast origin, use only records and weather information that would have been available at that issue cutoff.

  Fit imputation, encoding, scaling, feature selection, and other learned preprocessing within the training pipeline. Do not fit
these steps on validation or final-test data.
  Compare the count model with a persistence baseline that carries forward the most recent observed monthly count. Report
MAE and RMSE for the count forecast. If thresholded hotspot classes are separately evaluated, report per-class precision,
recall, F1, and a confusion matrix.
  Do not repeatedly tune against the final test period. After its one-time evaluation is recorded, a deployment model may be
